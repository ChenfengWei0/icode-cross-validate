# 第一步：只确定接口

下面是这次任务的需求条目集。这一步只做一件事：确定接口。

$items

要求：

1. 写出 C 头文件：函数声明、类型定义，并在注释里写明每个函数的前置条件（参数范围、调用顺序等）。**不要写任何实现**（不要创建 .c 文件，头文件里也不要写函数体）。
2. 写好后创建 `$cv/interface.json`，列出头文件和需要的 include 目录（相对项目根目录），例如：

```json
{"headers": ["include/account.h"], "include_dirs": ["include"]}
```

3. 不要读取或修改 `$cv/` 下的其他内容。

完成后用一句话说明你声明了哪些头文件。
